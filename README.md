# 决策科学学习笔记
由于CC上今年（2026秋）并没有发pdf版本的note，或是各种形式的课件。。。
只有分章节的，在各个页面上零碎呈现的，只能在线阅读的笔记。。。
所以我只能委托我的codex来帮我进行一下整理。
本项目整理自CC平台 Decision Science 课程资料，面向课程学习、英文考试复习和考前快速回顾。

## 文件说明

### 1. 完整合并版

文件：`决策科学_完整修订版.docx`

按照课程原始顺序整合六个模块，尽可能保留：

- 英文原文
- 课程公式
- 表格
- 统计图和分布图
- 流程图、状态转移图和网络示意图
- 课程案例与应用内容

同时移除了网页中的信息、问号、钥匙、视频等纯界面占位图，便于连续阅读。

适合：

- 系统通读课程内容
- 查阅英文原文
- 回看课程图表和详细解释
- 补充应试版中被压缩的内容

### 2. 应试精简版

文件：`决策科学_应试精简最终修订版.docx`

以中文理解为主，同时保留英文考试术语和英文答题表达，重点整理：

- 各模块核心概念
- 公式与符号解释
- Probability、Randomness 和 Distribution
- Discrete-Event Simulation
- Instrumentation、Verification 和 Validation
- Exploration、Experiment Design 和 Sensitivity
- Replication、Confidence Interval、Warm-up 和 Autocorrelation
- 常见英文简答题
- 综合建模题答题框架
- 高频易错点
- 考前最后一轮检查清单

适合：

- 考前复习
- 理解课程主线
- 记忆英文关键词
- 准备英文简答题和综合题

## 推荐使用顺序

1. 先阅读应试版，建立课程整体框架。
2. 遇到不理解的概念，再回到完整版查阅原文、公式和图表。
3. 考前重点复习应试版中的公式、比较表、答题框架和易错点。
4. 英文答题时保留专业术语，不建议完全翻译成中文。
